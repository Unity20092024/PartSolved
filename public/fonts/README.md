# Self-hosted editorial fonts

Inter and Manrope Latin variable WOFF2 assets are from the respective `@fontsource-variable/inter@5.3.0` and `@fontsource-variable/manrope@5.3.0` npm distributions. Both are licensed under the included SIL Open Font License. No third-party font request or build-time Google Fonts connection is required. Only the article reader and blog editor use these families; existing site branding is preserved.
